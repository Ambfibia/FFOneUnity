# reconstruction-studio

Read [Studio](../../../Docs/Studio/README.md) and [routes](../../../Docs/Studio/orchestration.json). Infer RECONSTRUCT, DEVELOP or HYBRID from the requested result. For a trivial local edit stay with one agent; for independent research or implementation plus review, delegate the smallest useful team using native subagents. Read the selected .codex/agents/<role>.toml; when the host cannot select a named role, include its developer_instructions in the delegated task and disclose this fallback.

Input: requested outcome, affected owners, current Git state. Assign one integrator and exclusive file ownership. Use a fresh bounded task with evidence, unknowns, permitted edits and acceptance criteria. Wait for dependent handoffs. Do not run all roles for every task. Errors or missing tools become explicit blocked checks; continue independent work. Output: reviewed diff/specification, evidence, preservation updates and checks with pass/fail/blocked/not-run. See [validation](../../../Docs/Studio/validation.md).
