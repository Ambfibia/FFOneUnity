## Что проверено

Сетевые сценарии выполнялись с локальным RustyFusion и отдельными SQLite-базами. Два игрока по очереди приглашали друг друга к обмену, перетаскивали вещи и подтверждали суммы Taros. После двух сделок проверены владельцы вещей, оба кошелька, движение и чат. Доступность карты проверена при переходе через портал. Для граничных состояний интерфейса использовались также подготовленные сообщения 0104. Нажатия и переподключение геймпада воспроизводились виртуальным устройством Unity Input System.
