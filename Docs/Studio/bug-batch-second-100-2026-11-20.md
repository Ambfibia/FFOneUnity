# Ещё 100 закрытых багов FFOne · 20 ноября 2026

В FFOne Studio закрыты 100 карточек, которые оставались открыты после предыдущей сотни. Для 58 потребовались изменения в этой партии. По 42 текущее поведение прошло повторную проверку. [Карточка задачи](dashboard/cards/studio-0ddb7e9b30fb.json) · [Сверка всех карточек и файлов](../../Logs/Studio/second-100-20261120/final-audit.json)

## Сборка и игровые проверки

В проверочной сборке Windows совпали контрольные суммы 2172 файлов Addressables, включая 2168 бандлов. На этой сборке прошли общий сценарий интерфейса, проверка музыки, холодный запуск, создание персонажа, обучение и вход в обычный мир. [Сборка Windows](../../Logs/Studio/second-100-20261120/final-build/receipt.json) · [Сверка каталога](../../Logs/Studio/second-100-20261120/pack-comparison.json) · [Итоговые прогоны](../../Logs/Studio/second-100-20261120/final-suites.json)

Для сетевых действий использованы отдельные локальные экземпляры RustyFusion и временные SQLite-базы. Часть узких проверок использовала инструментированные Windows-клиенты, тестовые профили и виртуальный геймпад Unity Input System. В таблице ниже у каждой карточки указаны конкретные действия и результаты. [Исходное состояние рабочих копий](../../Logs/Studio/second-100-20261120/baseline.json) · [Снимки экрана и записи звука](../../Logs/Studio/second-100-20261120/screenshots.html)

На RustyFusion все 238 тестов библиотеки прошли в трёх запусках — последовательно, с четырьмя потоками и с обычным числом потоков. При первом параллельном запуске проверка первого heartbeat завершилась ошибкой, затем тестовый процесс аварийно остановился с STATUS_ACCESS_VIOLATION.
