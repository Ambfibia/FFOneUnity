В двенадцати дополнительных анимациях танца FFR отсутствовали звуковые события. Для H6 использованы оригинальные инструментальные фрагменты стандартных танцев персонажей.

У пушки будущего сохранилась модель, а параметры выстрела для I5 восстановлены по тому же шестичастному орудию в соседней ячейке. В семи проверенных версиях Galaxy Gardens имеет зелёную или бирюзовую атмосферу. Фиолетовый оттенок для C173 подобран по замечанию автора.
